### Antes de rodar o projeto:

* Crie seu .env com os valores pedidos no .env.example

* Instale o Docker Desktop no seu computador (Se quiser usar o PostgreSQL local, pule esta etapa e a próxima)

* Para subir os contêineres:

``` bash
docker compose up
```

* Instale as dependências:

``` bash
pip install -r requirements.txt
```
